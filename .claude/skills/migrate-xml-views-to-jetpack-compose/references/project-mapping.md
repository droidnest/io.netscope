# Project mapping: NetScope

NetScope has no XML layouts, no XML theme attributes and no custom views, so there is nothing to map from XML.

When a project does have them, this file holds its tables, built with the method of `theme-mapping.md`:

1. **Colors**: the most used XML color attributes, their light / dark values, and the theme token or component that
   replaces each.
2. **Typography**: the XML text sizes and weights, and the theme's size and weight for each.
3. **Styles and shapes**: component styles of the layouts and the component parameters that replace them.
4. **Views to components**: the most frequent custom and plain views and their design system counterparts.
5. **Visual effects** the design system has variants for (blur, glass, shadow tints).
6. **Example**: one real layout of the project before and after.

For NetScope's Compose tokens (`NetScopeTheme`, `NetScopeSurface`, `ColorSuccess`…), see `project.md`.
